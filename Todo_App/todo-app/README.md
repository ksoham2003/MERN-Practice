# 📝 React Todo App

A modern Todo application built with React that demonstrates the core concepts of React development, including state management, component composition, CRUD operations, filtering, and data persistence using localStorage.

---

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as completed or pending
- 📊 Task statistics
- 🔍 Filter tasks (All / Completed / Pending)
- 💾 Persist tasks using localStorage
- ⚡ Built with functional components and React Hooks

- Total Tasks
- Completed Tasks
- Pending Tasks
